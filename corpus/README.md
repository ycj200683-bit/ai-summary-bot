# corpus —— 语料目录（正文不入库）

## 文件格式约定

每个 `NNN.txt` 结构固定三部分：

```
标题（第一行）
（空行）
正文（第三行开始，段落之间用空行分隔）
```

这样 `build_corpus.py` 一小段代码就能解析：

```python
title, body = text.split("\n\n", 1)
```

## 为什么 `.txt` 不进仓库

正文来自量子位（qbitai.com）等第三方媒体，**有版权**。本地留着自己跑批量摘要没问题，
但**不要提交到公开仓库**——这是数据合规的基本动作。`.gitignore` 已经把 `corpus/*.txt` 排除。

`index.tsv` 只记录「文件名 / 字数 / 日期 / 标题 / 原文链接」，也不入库。

## 本批语料（2026-10-16 ~ 10-19 采集）

- 来源：量子位公开 WordPress API（`/wp-json/wp/v2/posts`）
- 数量：**30 篇**（001~030）
- 字数：679 – 3992 字，均值 2703 字，全部 ≥500 字
- 只保留正文，已剔除署名行、参考链接、URL、HTML 标签、"获授权转载"声明

## 怎么补语料

```bash
python fetch_corpus.py              # 补到 30 篇（已有的不重复抓）
python fetch_corpus.py --target 50  # 想要更多
```

脚本会自己处理分页、去重、清洗、编号，并把元信息追加到 `index.tsv`。
注意它带 1 秒节流、只拉需要的页数——对方愿意公开接口，不代表可以无脑刷。

想混入其他来源，也可以手动放：挑科技/财经长报道，复制正文，
按「标题 → 空行 → 正文」的格式存为 `031.txt`、`032.txt`……

来源建议：36氪、虎嗅、机器之心、量子位、InfoQ 中文、澎湃科技。
