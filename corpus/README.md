# corpus —— 语料目录（正文不入库）

## 文件格式约定

每个 `NNN.txt` 结构固定三部分：

```
标题（第一行）
（空行）
正文（第三行开始，段落之间用空行分隔）
```

这样 `build_corpus.py` 一小段代码就能解析：

```python
title, body = text.split("\n\n", 1)
```

## 为什么 `.txt` 不进仓库

正文来自量子位（qbitai.com）等第三方媒体，**有版权**。本地留着自己跑批量摘要没问题，
但**不要提交到公开仓库**——这是数据合规的基本动作。`.gitignore` 已经把 `corpus/*.txt` 排除。

`index.tsv` 只记录「文件名 / 字数 / 日期 / 标题 / 原文链接」，也不入库。

## 本批语料（2026-10-18 采集）

- 来源：量子位公开 WordPress API（`/wp-json/wp/v2/posts`）
- 数量：10 篇（后续补到 ≥30 篇）
- 字数：1013 – 3839 字，全部 ≥500 字
- 时间：2026-10-16 ~ 10-17
- 只保留正文，已剔除署名行、参考链接、URL、HTML 标签

## 如何补到 30 篇

手动补：挑科技/财经长报道，复制正文，按上面格式存为 `011.txt`、`012.txt`……
要求：中文、≥500 字、只要正文（去掉导航/评论/广告/参考资料）。

来源建议：36氪、虎嗅、机器之心、量子位、InfoQ 中文、澎湃科技。
